# Ginlon 站点视觉重设计 —「极简静默」方向设计规范

- 日期：2026-06-22
- 方向：探索全新视觉方案（保留品牌气质，配色与字体可调）
- 风格：极简静默（Quiet Minimal）
- 范围：设计规范 + 首页落地设计稿（用 Pencil 产出）

## 1. 目标与定位

在保留"自然、沉静、长期主义、文人感"品牌气质的前提下，探索一套全新的极简视觉方案。
核心理念：**大面积留白，绿色收敛点睛，衬线统一全站，靠排版节奏而非装饰承载内容。**

本次交付：
1. 一套可复用的设计规范（色彩、字体、间距、组件基调）。
2. 用「首页」把规范落地为完整设计稿，验证整体方向。

确认后再迭代扩展到列表页、详情页等其他页面（不在本次范围）。

## 2. 色彩规范

延续品牌绿，但大幅收敛——绿色仅用于点睛（链接、关键标记、极少装饰线），
内容分隔主要依赖留白与发丝线，几乎不使用卡片阴影。

### 浅色模式（主）

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 page-bg | `#FAF8F3` | 纯净暖白纸张 |
| 表面 surface | `#FFFFFF` | 极轻，几乎无边框无阴影 |
| 主文字 text-strong | `#1A1F1C` | 近黑，沉稳 |
| 次文字 text-muted | `#6B756F` | 灰绿调 |
| 强调绿 accent | `#2F6B4F` | 链接、关键标记、极少装饰线 |
| 分隔线 hairline | `rgba(26,31,28,0.08)` | 极细发丝线，替代卡片边框 |

### 深色模式

| 角色 | 色值 |
|------|------|
| 背景 page-bg | `#131714` |
| 表面 surface | `#1A201C` |
| 主文字 text-strong | `#E8EDE9` |
| 次文字 text-muted | `#9CA8A1` |
| 强调绿 accent | `#6FBF98` |
| 分隔线 hairline | `rgba(232,237,233,0.10)` |

## 3. 字体规范

衬线统一全站（不保留现有楷体），唯一例外是元信息使用小字无衬线做克制点缀。

| 角色 | 字体 | 说明 |
|------|------|------|
| 标题 | 衬线（Source Han Serif SC / Noto Serif SC） | 字号层级拉大，靠大小制造节奏 |
| 正文 | 衬线（同上，常规字重） | 阅读体验为先，行高 1.8 |
| 标签 / 元信息 | 无衬线（小字、宽字距 0.08em） | 全站唯一非衬线元素 |

## 4. 间距与排版尺度

间距刻度（8px 基准，留白偏大）：`4 · 8 · 16 · 24 · 40 · 64 · 96 · 128`

字号层级：

| 角色 | 字号 | 字重 | 备注 |
|------|------|------|------|
| Display | 56px | 600 | 衬线 |
| H1 | 36px | 600 | 衬线 |
| H2 | 24px | 600 | 衬线 |
| Body | 17px / 行高 1.8 | 400 | 衬线 |
| Meta | 13px / 字距 0.08em | 500 | 无衬线 |

容器宽度：阅读区 `680px`，外壳 `1000px`（比现状更窄，更聚焦）。

造型基调：
- 圆角：小（4–8px），局部直角；去掉现有大圆角。
- 阴影：几乎不用。
- 留白：超大，单栏为主，行高宽松。

## 5. 首页布局结构

延续现有首页内容模块（Hero / 精选写作 / 当前关注 / 页脚），用"静默"方式重排。

- **顶栏**：无背景，发丝线分隔；左 Logo「Ginlon」，右导航 + 主题切换。
- **Hero**：保留头像（小尺寸、无边框圆形，融入留白）；超大衬线标题 + 标语；去掉背景卡片与边框。
- **精选写作**：从卡片改为**目录清单式**——每条为「日期 · 标题 · 一句摘要」，发丝线分隔，无卡片无阴影。
- **当前关注**：去掉卡片，纯文字列表（小标题 + 一行说明）。
- **页脚**：极简，版权 + GitHub / RSS 链接。

### 关键变化 vs 现状

- 文章列表：卡片 → 目录清单。
- Hero：去背景卡片，保留小头像。
- 当前关注：去卡片，纯文字列表。
- 整体：绿色出现频率下降，留白显著增大，衬线统一。

## 6. Pencil 交付物结构

在 `designs/ginlon-redesign.pen` 中产出：

1. **设计规范画板**：色彩样本（浅/深）、字体层级样例、间距刻度、组件基调示例。
2. **首页设计稿画板**：浅色模式完整首页（桌面端，宽度 1000px 外壳）。
3. （可选）深色模式首页或移动端，视确认后再补。

设计变量（颜色、字号）尽量登记到 .pen 的 variables 中，便于主题切换与未来落地为 CSS。
