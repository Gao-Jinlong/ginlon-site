# 光与影

非常不一样的情感体验，不像黑神话那样宏大命题

命题足够小，小到一句：

“家人之间的事情总是复杂的”

就能概括

却又足够深刻

"你应该自己选择你要过的人生"

“如何面对死亡，面对分别的命题”

“下辈子见”

西方的情感表达，直接，自我，陪伴，

东方的情感表达，含蓄，克制，牺牲


该省省该花花的极致体现
