# 光与影

非常不一样的情感体验，不像黑神话那样宏大命题

命题足够小，小到一句：

“家人之间的事情总是复杂的”

就能概括

却又足够深刻

"你应该自己选择你要过的人生"

“如何面对死亡，面对分别的命题”

“下辈子见”

西方的情感表达，直接，自我，陪伴，

东方的情感表达，含蓄，克制，牺牲


该省省该花花的极致体现



古斯塔夫初次登岛时的因恐惧而失去反抗能力，到后来勇敢地面对实力悬殊的敌人，用自己的牺牲为远征队扫清障碍。
艾尔玛在画中的一生永远积极昂扬，充满斗志，可当她回到真实的世界知晓一切后，面对虚幻和真实的选择，她却选择逃入虚无，因为她在哪里长成了她希望中的自己。
现实中的我们何尝不是如此，平时的积极昂扬不过是因为核心的立场没有被挑战，在真正的灾难性冲击前会陷入窒息，失去对自我的控制能力坠入深渊，而此时，周围的亲友便成为了将我们引出深渊的北极星，在我们的脆弱处建立支撑，指引我们重新找回自己的方向。
关于个人的成长，关于亲友间的感情，如此深刻。

用一生去爱和用一生去绘的结尾标题也暗示了打破困境的方式就是唯有爱能克服一切

玛埃尔的一生就像我们现在常说的 重新养育自己
